# Структура поэтапно:
1. llm
2. Папка с пдф
3. отдельные этапы с тестированным выводом:
- Эмбеддинги для индексирования
- Разбивка PDF на чанки по 800 символов
- Векторный индекс chroma базы знаний

- RAG пайплайн внутри @tool
Пайплайн:
Индексация:
1. Загрузка всех PDF из директории с помощью PyPDFLoader
2. Чанкование с помощью RecursiveCharacterTextSplitter
3. Эмбеддинги - Превращение текста чанков в векторы
4. Создание chromadb индекса, Сохранение и загрузка chromadb индекса в папку базы знаний
Поиск (tool):
1. Получение вопроса от пользователя
2. Использование HyDE - вызов к LLM, генерация гипотетического ответа на вопрос
3. Создание Retriever (берем топ 15-20 чанков)
- выбор ответа HyDE
- эмбединги через модель
- similarity_search (поиск по сходству) в chromadb
4. Реранжирование cross-encoder + reranking
- ориг вопрос и выбранные моделью чанки
- cross-encoder дает каждому чанку оценку релевантности
- reranking по оценкам
- выбор топ 3-5 чанков и возврат их агенту




- Загрузка 14 PDF из knowledge_sources/

- Веб-поиск в реальном времени Tavily API
